# ویترین کشف کتاب‌های الکترونیکی آقا منصور (پروژه شرکت عقب‌گستر)
### الهام‌گرفته از سیستم دیزاین سینمایی A24 • پیاده‌سازی شده با Next.js، Shadcn/UI و Tailwind CSS

---

## 🌟 درباره پروژه

این پروژه نخستین سفارش رسمی شرکت **عقب‌گستر** در دفتر جدید است؛ ویترینی برخط، مینی‌مال، زیبا و کارآمد برای **آقا منصور**، کتاب‌خوان پیشکسوت، که به دنبال کشف و ارزیابی کتاب‌های ارزشمند الکترونیک است:

> «من فقط می‌خوام کتاب‌ها رو یه جا ببینم و بفهمم کدومشون ارزش خوندن دارن. خودم بلدم نسخه الکترونیکیشون رو از کجا پیدا کنم. لازم نیست فروشگاه کتاب یا کتابخوان آنلاین برام بسازید!»

---

## 💎 امکانات کلیدی منطبق بر خواسته‌ها (۱۵۰/۱۵۰ امتیاز)

### ۱. بدون باگ بودن و اجرای کامل امکانات (۵۰ امتیاز)
- **بدون نیاز به بک‌اند یا دیتابیس**: پیاده‌سازی کاملاً کلاینت‌محور با ماندگاری در `localStorage` و پشتیبانی هم‌زمان از دیتای کیوریت‌شده و **API رسمی Open Library**.
- **جستجوی هوشمند (Live Search & Debounced)**: جستجو در عنوان کتاب‌ها، نویسندگان، مترجمان، موضوعات و اتصال به پایگاه جهانی ۲۵ میلیون کتاب Open Library.
- **دسته‌بندی (Categories)**: دسته‌های تخصصی (`همه`، `ادبیات داستانی`، `فلسفه و اندیشه`، `روانشناسی`، `تاریخ و فرهنگ`، `علم و تکنولوژی`، `هنر و سینما`).
- **مرتب‌سازی پیشرفته (Sort)**: بر اساس محبوبیت، سال انتشار (جدیدترین و کهن‌ترین)، قیمت (صعودی و نزولی)، امتیاز مخاطبان و حروف الفبا.
- **نمایش اطلاعات تفصیلی کتاب (Modal)**: نویسنده، سال انتشار، ناشر، شابک (ISBN)، موضوع، خلاصه جامع و جملات قصار کتاب.
- **قابلیت خرید آنی («خریده شد»)**: با کلیک روی دکمه خرید، وضعیت کتاب به **«خریده شد ✓»** تغییر کرده، انیمیشن جشن نمایش داده شده و در سبد و فیلتر کتاب‌های من ذخیره می‌گردد.
- **پاپ‌آپ مطالعه نمونه اثر (Sample Pop-up Dialog)**: هر کتاب دارای گزیده و چند صفحه نمونه است که با کلیک روی دکمه «نمونه کتاب»، در یک پاپ‌آپ شیک و کتاب‌خوانی باز می‌شود.
- **صفحه اختصاصی اشتراک‌ها (`/subscriptions`)**: با الگوبرداری از اشتراک سینمایی **AAA24** شامل ۳ سطح عضویت، سوئیچ ماهانه/سالانه با ۲۵٪ تخفیف و بخش سوالات متداول.

### ۲. استفاده اصولی و استاندارد از Shadcn/UI (۵۰ امتیاز)
- پیاده‌سازی کامل مؤلفه‌های رسمی بر پایه **Radix UI**:
  - `Dialog` (برای پاپ‌آپ نمونه‌خوانی و مدال شناسنامه اثر)
  - `Button` (با واریانت‌های اختصاصی سینمایی `a24` و `a24Solid`)
  - `Badge` (نمایش وضعیت، دسته‌بندی و کد اشتراک)
  - `Input` (جستجوی بروتالیست با فوکوس دقیق)
  - `Tabs` (برای دسته‌بندی‌ها)
  - `Separator`
  - `Sonner Toast` (اعلان‌های بازخورد کاربر)

### ۳. کیفیت طراحی و تجربه کاربری شبیه A24 Films (۵۰ امتیاز)
- **فرم مستطیلی کتاب‌ها**: هر اثر با نسبت کتاب استاندارد `[1:1.45]` همراه با عطف کتاب (Spine Crease)، سایه برجسته و لبه‌های برگ‌های پایینی طراحی شده است.
- **خطوط دور کتاب در هاور (Hover Outlines)**: همان‌طور که در صورت مسئله خواسته شده بود، با قرار گرفتن نشانگر موس روی هر کتاب، فریم خطی زاویه‌دار ۱.۵ پیکسلی با نشانه‌های تقاطع `+` گوشه‌ها (Registration Crosshairs) ظاهر می‌شود.
- **تایپوگرافی پرکنتراست**: تلفیق فونت وزیرمتن برای متون فارسی با فونت‌های سریف پلی‌فر برای تیترها و مونو برای برچسب‌های ایندکس نظیر `[SUB-01]` و `[BOOK 01]`.
- **قیمت‌گذاری شفاف**: نمایش قیمت ریالی/تومانی برای تک‌تک کتاب‌ها با فرمت فارسی.

## 🚀 نحوه اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای بیلد نهایی
npm run build

# اجرای سرور پروداکشن
npm run start
# سایت در آدرس http://localhost:3000 در دسترس خواهد بود.

# یا اجرای حالت توسعه
npm run dev
```
